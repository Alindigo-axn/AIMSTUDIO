# AIM Studio — Landing Page

Одностраничный лендинг цифрового агентства **AIM Studio** (веб-разработка, UI/UX, мобильные приложения, брендинг, SEO, AI-интеграции). Полностью статичная страница на чистом HTML/CSS/JS, без сборщиков и фреймворков — открывается прямо в браузере.

## Стек

- **HTML5 + CSS3** — вся стилизация в `<style>` внутри одного файла, переменные через `:root` (тёмная палитра: чёрный фон `#0a0a09`, акцент лайм `#c8f53c`).
- **Vanilla JavaScript** — без сторонних библиотек, всё поведение (языки, анимации, аккордеон, карта, видео-грид) написано вручную.
- **Google Fonts**: `Fraunces` (засечный, для заголовков), `Geist` (основной текст), `JetBrains Mono` (лейблы/эйброу-теги).
- Внешние медиа подтягиваются по прямым ссылкам: изображения с Unsplash, логотипы с svgl.app, видео-превью проектов с cdn-luma.com.

## Мультиязычность (EN / RU / KZ)

- Весь текст продублирован тремя `<span data-lang="en|ru|kz">` блоками; активный язык переключается CSS-классом `lang-active`.
- Переключатель `.lang-switcher` в шапке и в мобильном меню.
- Выбор языка сохраняется в `localStorage` (`aim_lang`) и подставляется при следующем визите.

## Структура секций

1. **Навигация (`nav`)**
   - Плавающая «капсула»-шапка, при скролле сжимается и получает блюр-фон (`backdrop-filter`).
   - Бургер-меню на мобильных с полноэкранным drawer'ом и анимацией открытия/закрытия.
2. **Hero**
   - Анимированный заголовок и бейдж с последовательным fade/rise-in появлением (`@keyframes riseIn`).
   - Кастомные CTA-кнопки `.flow-btn` с эффектом «жидкого» перелива фона по кругу и сдвигом стрелок при наведении.
3. **Sticky-скролл со скриншотом**
   - Секция высотой 180vh: карточка со скриншотом дашборда наклоняется в 3D (`perspective`, `rotateX`) и выравнивается по мере скролла (расчёт прогресса + easing в JS).
4. **Лента логотипов партнёров/технологий**
   - Бесконечная CSS-анимация прокрутки (`logoScroll`), останавливается при наведении курсора.
5. **Services — «Что мы делаем»**
   - Сетка из 6 карточек услуг (веб, UI/UX, мобильные, брендинг, SEO, AI).
   - Курсорный «spotlight»-эффект на каждой карточке (координаты мыши пробрасываются в CSS-переменные `--mx`/`--my`).
6. **Process — «Как мы работаем»**
   - Аккордеон из 5 шагов (Discovery → Strategy → Design → Development → Launch), с точками-пипсами прогресса и кнопкой «Следующий шаг».
   - Каждый пункт разворачивается через `grid-template-rows` transition (плавно, без `height:auto`-скачков).
7. **Cases / Portfolio — «Dynamic Frame Layout»**
   - Сетка 3×3 из видео-превью проектов; при наведении (или тапе на мобильном) ячейка увеличивается, а остальные сжимаются, видео начинает воспроизводиться.
8. **About Us**
   - Манифест студии, счётчики-статистика (47+ проектов, 5 лет на рынке, 98% возвращаются), список ценностей.
   - Команда: аватары с "пружинным" тултипом, который наклоняется и сдвигается в зависимости от положения курсора (кастомная физика на `requestAnimationFrame`).
9. **Contact**
   - Контактные данные (телефон, email, сайт, адрес) с иконками.
   - Форма обратной связи (имя, фамилия, email, тема, сообщение) — **только фронтенд**, реальной отправки нет: при клике на кнопку показывается имитация "Сообщение отправлено" на 3 секунды.
   - Интерактивный SVG-виджет карты (Астана): анимированная прорисовка "дорог" (`stroke-dashoffset`), 3D-наклон по курсору, разворачивается по клику/тапу.
10. **Footer**
    - Карта сайта (услуги, студия, соцсети), копирайт, иконки соцсетей (Telegram, Instagram, LinkedIn).

## Визуальные эффекты

- Анимированные градиентные "блобы" на фоне (`mesh-blob-1/2`) с лёгким параллаксом от движения мыши.
- Полупрозрачная сетка (`grid-lines`) и SVG-шум (`feTurbulence`) поверх всего сайта для "плёночной" фактуры.
- Скролл-анимации появления элементов через `IntersectionObserver` (класс `reveal-on-scroll` → `visible`).
- Адаптивная вёрстка с брейкпоинтами под мобильные устройства, отдельные значения анимаций для мобильного/десктопного скролл-эффекта.

## Особенности реализации

- Всё — в одном HTML-файле (инлайн `<style>` и `<script>`), удобно для быстрого деплоя как статическая страница.
- Нет зависимостей от npm/сборщиков — можно открыть файл прямо в браузере.
- Форма обратной связи не подключена ни к какому бэкенду/API — требуется добавить обработчик отправки (например, fetch на свой сервер, Formspree, Telegram Bot API и т.п.), если нужна реальная отправка заявок.
- Все внешние изображения и видео подгружаются с чужих CDN (Unsplash, svgl.app, cdn-luma.com) — для продакшена рекомендуется заменить на собственные хостируемые файлы.
- Placeholder-контакты и адрес (телефон, email, соцсети, координаты) — нужно заменить на реальные данные компании перед публикацией.

## Как запустить

Просто откройте `AIM_Studio.html` в браузере — сборка и сервер не требуются.

## Возможные доработки

- Подключить реальную отправку формы (бэкенд/API или сторонний сервис).
- Заменить статичный SVG-виджет карты на встроенную карту (Google Maps / Yandex Maps / Mapbox).
- Вынести CSS/JS в отдельные файлы для более удобной поддержки.
- Заменить видео и изображения из внешних источников на собственные.
